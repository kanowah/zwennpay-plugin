# ZwennPay QR Payment Gateway for WordPress

The official ZwennPay plugin that enables QR code payments directly on your WooCommerce checkout page.

---

## 📌 Description

ZwennPay QR allows customers to complete payments by simply scanning a QR code using their mobile banking app.  
This plugin integrates seamlessly with WooCommerce and provides a smooth, secure checkout experience.

---

## ⚠️ Requirements

Before using this plugin, you must install and activate:

- WordPress (latest version recommended)
- WooCommerce (required)

👉 Without WooCommerce, this plugin will not function.

---

## 🚀 Features

- Generate QR code for each order
- Real-time payment status checking
- Custom payment instructions
- Automatic checkout page setup
- Easy integration with WooCommerce

---

## 🛠 Installation

1. Upload the plugin folder to: 
/wp-content/plugins/


2. Go to WordPress Admin → Plugins

3. Activate **ZwennPay QR Payment Gateway**

4. Make sure WooCommerce is installed and activated

---

## ⚙️ Setup

1. Go to:
WooCommerce → Settings → Payments


2. Enable **ZwennPay QR**

3. Configure:
- Merchant details
- Payment instructions (optional)

4. Save changes

---

## 💳 How It Works

1. Customer places an order
2. ZwennPay displays a Scan and Pay QR code
3. Customer scans using any mobile banking app
4. Payment status is checked automatically
5. Order updates upon successful payment

---

## 📄 Checkout Page

On activation, the plugin can automatically:

- Create a checkout page
- Set it as the default WooCommerce checkout

---

## ❗ Troubleshooting

- **Payment method not showing?**
- Ensure WooCommerce is installed and active
- Ensure the payment gateway is enabled

- **QR not loading or API errors?**
- Verify credentials
- Check browser console for errors
